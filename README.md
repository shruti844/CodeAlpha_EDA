CodeAlpha_EDA

Exploratory Data Analysis of Books Dataset

This project performs Exploratory Data Analysis (EDA) on a dataset of 1,000 books collected from Books to Scrape using Python.

Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

Analysis Performed

* Dataset overview and structure
* Data types and statistical summary
* Missing values and duplicate checking
* Book price analysis
* Price distribution using histogram
* Outlier detection using boxplot
* Top 10 most expensive books
* Price category analysis
* Book availability analysis

Key Findings

* Total records: 1,000 books
* Average book price: Approximately £35.07
* All 1,000 books were marked as in stock.
* No missing values or duplicate rows were found.

Files Included

* CodeAlpha_EDA.ipynb – Jupyter Notebook containing the EDA analysis.
* CodeAlpha_WebScraping (1).csv – Dataset used for analysis.

Conclusion

The EDA helped understand book price distribution, availability, and overall data quality through Python libraries and visualizations.

Project completed as part of the CodeAlpha Data Analytics Internship.
